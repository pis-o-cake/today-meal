# ‘오늘 뭐 먹지?’ 발표 스토리보드 (4판)

발표 7분(시연 영상·Claude Design 창 전환 포함) + 별도 질의응답 3분. 9장, 목표 **6분 45초**.
웹 슬라이드는 `slides/index.html`, 발표자 대본·노트·시간은 `slides/presenter.html`(청중 화면에서 `P`).
청중 화면에는 핵심 문구만 두고, 문장은 발표자 대본으로 분리한다.

- 중심 문장: **“오늘 뭐 먹지?”라는 고민을, 냉장고를 비우는 한 끼로 연결합니다.**
- 앱 설명은 사용 상황과 실제 결과 중심, AI 설명은 선택 이유와 해결한 문제 중심.

**시간 검증: 미완료.** 리허설로 영상 재생·창 전환까지 포함해 다시 잰다.

## 장별 메모

- **3장:** 실제 앱 화면(`assets/img/home-*.png`, 10/1 녹화). 빨리 칸 화면의 추천 메뉴는 영상 메뉴와 달라 이름을 말하지 않는다.
- **4장:** 실제 결과 화면(`rec-egg10/8/4.png`) 한 장을 발화에 맞춰 바꾼다. 작은 화면을 여러 개 나열하지 않는다.
- **5장:** 추천 메뉴·조리 타이머 실제 화면(`menu-list.png`, `cook-timer.png`). 유튜브 조리는 재고를 자동으로 빼지 않는다. 재고 반영에는 “추천 메뉴 조리 완료 시”를 붙였다.
- **6장:** `assets/video/demo.mp4` = 90초 v4 AI 후시 녹음판(`today-meal-90s-v4-ai-voice-leda.mp4`, 87초). 사람 목소리만 AI 음성, 앱 응답·신호음은 실제 녹화음, 화면에 “사용자 음성 · AI 후시 녹음” 표기. 풀버전은 본인 목소리. 영상 중에는 설명하지 않는다. 복합 등록·대화식 정정·4인분은 영상에 없다.
- **7장:** GPT / Astra → Claude Design(창 전환) → Claude Code → 기존 자체 도구 engsys(AI 모델이 아님) → “시연 영상 편집과 웹 발표자료 제작에도 AI 활용”.
- **8장:** Gemini는 유튜브 URL 입력을 공식 지원해 선택, 명령 해석·추천도 통일. 호출어는 기기 음성인식 결과에 발음 유사성 규칙을 적용. 모델 재학습이 아니다.
- **9장:** AI 도구를 다시 나열하지 않는다.
