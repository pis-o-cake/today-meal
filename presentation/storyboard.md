# ‘오늘 뭐 먹지?’ 발표 스토리보드 (6판)

발표 7분(시연 영상 포함) + 별도 질의응답 3분. 9장, 목표 **6분 30초**.
웹 슬라이드는 `slides/index.html`, 발표자 대본·노트·시간은 `slides/presenter.html`(청중 화면에서 `P`).
청중 화면에는 핵심 문구만 두고, 문장은 발표자 대본으로 분리한다.

- 중심 문장: **“오늘 뭐 먹지?”라는 고민을, 냉장고를 비우는 한 끼로 연결합니다.**
- 앱 설명은 사용 상황과 실제 결과 중심, AI 설명은 선택 이유와 해결한 문제 중심.
- 글꼴: 표지 제품명·장 제목·마지막 중심 문구는 배민 주아체, 본문·표·수치·조작 안내는 Pretendard.
- 5판 변경: 대상 사용자와 기록 부담(2장), 기한 설명 압축(3장), 영상 레시피 연결과 차감 범위(5장),
  실제 개발 사례(7장), AI·서버 역할과 검증 범위(8장), 다음 검증 목표(9장).
- 6판 변경: 7장을 단계별 표(도구 → 실제 한 일 → 직접 판단)로 되돌리고 목업 비교 이미지를 뺐다. 9장에 사용자 흐름 회수 문구를 더했다.
- 새 성과 수치나 검증 결과를 만들지 않는다. 확인한 자료(편집 기록·검증 기록·커밋) 안에서만 말한다.

**시간 검증: 미완료.** 영상 재생까지 포함한 리허설로 다시 재고 이 표를 고친다.
말하는 부분만 초당 5음절로 세면 약 5분 30초(영상 87초 포함)라, 장 넘김과 숨 고르기를 더해 6분 30초를 잡았다.
발표 한도는 영상 포함 7분이다.

## 장별 메모

- **2장:** 1~2인 가구는 초기 대상 가정이다. 사용자 조사 결과처럼 말하지 않는다. 두 번째 문제(기록 부담)가 4장 음성 기록으로 이어진다.
- **3장:** 실제 앱 화면(`assets/img/home-urgent.png`·`home-unknown.png`, 10/1 녹화). ‘먼저 쓸 재료’와 ‘기한 미확인 재료’만 설명하고 나머지 두 칸은 이름만 둔다.
  빨리 칸 화면의 추천 메뉴는 영상 메뉴와 달라 이름을 말하지 않는다.
- **4장:** 실제 결과 화면(`rec-egg10/8/4.png`) 한 장을 발화에 맞춰 바꾼다. 첫 문장으로 2장의 기록 부담과 잇는다.
- **5장:** 추천 메뉴·조리 타이머 실제 화면(`menu-list.png`, `cook-timer.png`). 추천 조리 완료 시 조리한 인분 기준으로, 재고와 수량을 맞출 수 있는 재료를 차감한다.
  영상 레시피 카드에 “재고 자동 차감 없음”을 청중 화면에 표시한다.
- **6장:** `assets/video/demo.mp4` = 90초 v4 AI 후시 녹음판(`today-meal-90s-v4-ai-voice-leda.mp4`, 87초). 사람 목소리만 AI 음성, 앱 응답·신호음은 실제 녹화음.
  화면의 “사용자 음성 · AI 후시 녹음”·대기 단축·단계 생략 표시는 유지한다. 장면별로 촬영해 이은 영상이므로 전체 과정의 재고 정합성 검증으로 설명하지 않는다.
  복합 등록·대화식 정정·4인분은 영상에 없다.
- **7장:** 개발 전 과정을 단계별로 보인다. 행마다 활용 도구 → 실제 한 일 → 직접 판단(방향 결정·시안 선택·실기기 검수·적용 기준 결정).
  디자인은 한 행으로만 다루고 Claude Design 창 전환·목업 비교 이미지는 쓰지 않는다. engsys는 AI 모델이 아닌 기존 개발 지원 도구로 표시한다.
  실기기 수정은 커밋 6dacd9a의 호출 응답 수정(“네?” 낭독 → 짧은 신호음 뒤 바로 듣기)이다. 마지막 줄: “AI로 초안을 만들고 구현을 진행하되, 방향 선택과 실기기 검수는 직접 맡았습니다.”
- **8장:** AI는 말과 영상을 해석하고, 서버는 대상과 수량을 검증해 저장한다. Gemini는 유튜브 URL 입력을 공식 지원해 선택했다.
  호출어는 기기 음성인식 결과에 발음 유사성 규칙을 적용했고 재학습이 아니다. 전체 인식 품질을 검증한 것으로 말하지 않는다. 호출 감지는 앱 전경에서만 동작한다.
  시연에서 확인: 음성 등록·사용량·잔량 보정·추천 조리 후 차감·영상 레시피 분석. 검증 전: 호출 인식률·iOS 설치·정정·취소의 실기기 확인.
  테스트 수치는 발표에서 말하지 않고, 질문 시 발표자 노트의 날짜·커밋과 함께만 답한다.
- **9장:** 별도 감사 페이지 없이 마무리한다. 순서는 사용자 흐름 회수 → 다음 검증 목표 → 중심 문장 → 감사 인사(약 20초).
  화면은 냉장고 캐릭터와 중심 문구를 유지하고, 흐름 회수 보조 문구와 다음 검증 한 줄만 작게 둔다. AI 도구를 다시 나열하지 않는다.
