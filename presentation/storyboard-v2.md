# ‘오늘 뭐 먹지?’ 발표 스토리보드 v2

발표 7분 이내(시연 영상 포함) + 별도 질의응답 3분. 9장, 목표 **6분 30초**.
웹 슬라이드는 `slides-v2/index.html`, 발표자 대본·노트·시간은 `slides-v2/presenter.html`(청중 화면에서 `P`).
기존판(`storyboard.md`, `slides/`)은 그대로 두고 비교용으로 남긴다.

- 핵심 주장: **재료를 기록하는 데서 끝내지 않고, 메뉴 선택·조리·남은 재고까지 연결한다.**
- 남길 것 세 가지: 집중한 사용자 문제, AI를 쓰며 개발자가 한 판단과 검증, 확인한 결과와 앞으로 검증할 것.
- 음식물 낭비 감소·시간 절약·지속 사용 효과는 검증 전이라 성과로 말하지 않는다.
- 청중 화면은 주장과 증거만 두고, 설명은 발표자 대본으로 뺀다.

## 기존판과 다른 논리

| 기존판 | v2 |
|---|---|
| 기능 소개 3장(기한별 홈·음성 기록·메뉴) 뒤 시연 | 흐름 지도 1장으로 줄이고 “영상에서 볼 것”을 먼저 말한다 |
| 시연 직후 AI 도구 소개 | 시연 직후 **확인한 것과 보여주지 않는 것**을 정리한다 |
| 기술 선택(Gemini·호출어) 중심 8장 | **AI는 해석, 서버는 검증**을 명령 예시 하나로 보인다. 호출어 상세는 빼고 전경 한정만 남긴다 |
| 7장 도구 표 | 표에 결과물·직접 판단을 두고 실기기 수정 사례 하나를 붙인다 |
| 마무리에서 다음 목표 한 줄 | 8장을 **성패를 가를 질문 세 가지**로 따로 둔다 |

## 장별 근거와 주의

- **1장:** 도구·기술 이름을 꺼내지 않는다.
- **2장:** 1~2인 가구는 초기 대상 가정이다. 조사 결과나 통계처럼 말하지 않는다.
- **3장:** 화면은 `rec-egg10`·`home-urgent`·`cook-timer`(10/1 실기기 녹화)와 `cook-done`(90초 v3 영상 73.5초 프레임).
  추천 조리 완료는 조리한 인분 기준으로 맞출 수 있는 재료만 뺀다. 유튜브 레시피 조리는 자동 차감이 없다.
- **4장:** `assets/video/demo.mp4` = `demo/final/voiceover/today-meal-90s-v4-ai-voice-leda.mp4`(87초).
  사용자 목소리만 AI 후시 녹음, 앱 응답·신호음은 실제 녹화음. 후시 녹음·대기 단축·단계 생략 표시는 유지한다.
  영상 중에는 말하지 않는다. 정정·취소·복합 등록·4인분 변경은 영상에 없다.
- **5장:** 근거는 `demo/final/EDIT-NOTES.md`. 안드로이드 실기기 1대, 장면별 촬영 후 편집이다.
  편집 기록의 한계: 05 끝 냉장고 화면은 계란이 10개로 찍혀 뺐다(장면 사이 재고가 이어진다고 말하지 않는다),
  04 기록 화면의 영어 “undo” 말풍선, 05 메뉴 상세의 재료가 모두 “있어요”로 보이는 표시 오류(촬영 뒤 서버에서 고침).
- **6장:** 구현 근거는 `server/app/domain/command/validation.py`·`inventory/service.py`·`command/service.py`(되묻기·전부 아니면 반영 안 함·이력·취소·정정).
  부분 반영은 미구현 목표(검증 기록 R-01). Gemini 유튜브 URL 입력은 공식 문서
  (ai.google.dev/gemini-api/docs/video-understanding, 2026-09-23 갱신) 기준 **프리뷰** 기능이며 공개 영상만 된다. 화면에도 “프리뷰”를 적었다.
- **7장:** 목업은 표의 한 행으로만 다루고 Claude Design 창 전환은 하지 않는다. engsys는 기존 개발 지원 도구이며 AI 모델이 아니다.
  사례 근거: `app/lib/core/voice/listening_cue.dart`(9/30 22:49 작성, 커밋 6dacd9a)와 9/30 23:13 이후 촬영본 받아쓰기(EDIT-NOTES). 정량 개선 효과는 말하지 않는다.
- **8장:** 확인 방법은 제안이다. 실행했거나 일정이 잡힌 계획처럼 말하지 않는다. 호출은 앱 전경에서만, 실기기 확인은 안드로이드뿐이다.
- **9장:** 별도 감사 페이지 없이 끝낸다. AI 도구를 다시 나열하지 않는다.

## 근거가 부족해 넣지 않은 주장

- 음식물 낭비 감소, 시간 절약, 지속 사용 효과
- 1~2인 가구의 불편을 조사로 확인했다는 표현이나 통계
- 음성 인식률·호출 정확도, 신호음 수정의 정량 개선
- 처음부터 끝까지 이어진 재고 정합성(장면별 촬영 편집본)
- GPT/Astra의 구체 산출물(기록이 없어 “선택지 비교, 구현 방향 정리”까지만)
- 자동 테스트 수치(질문 시에만 날짜·커밋과 함께)

## 발표 전 준비

| 무엇 | 확인 |
|---|---|
| 슬라이드 | `slides-v2/index.html` → `F` 전체 화면, `P` 발표자 창. 1장에서 발표자 창 **발표 시작**을 눌러야 전체 시간을 잰다 |
| 시연 영상 | 4장에서 Space 재생. 받는 중이면 “영상 준비 중”으로 머물다 바로 재생, 열 수 없으면 안내가 뜬다 → 같은 파일을 플레이어로 전체 화면 |
| 키 입력 | 발표자 창 대본의 녹색 키 줄이 누를 시점이다. 장마다 마지막 Space 가 다음 장으로 넘긴다 |
| 리허설 | 영상 재생까지 포함해 전체 시간을 재고 이 표 갱신 |
