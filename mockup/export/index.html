· 조리: AI 추천 3개, 줄마다 재료 상태(재료 다 있어요 / 재료 준비 후), 제목 옆 새로 받기, 고르는 동안 캐릭터 + ‘냉장고를 뒤져보는 중’ + 바뀌는 한 줄 + 점 3개. 소요시간 배지 없음

· 기록: 오래된 것 위, 최근 아래, 열면 끝을 보여줌. 되돌리기는 가장 최근 줄에만. 카드 문장은 동작마다 고정(넣은 만큼 채웠어요 / 쓴 만큼 뺐어요 / 남은 양을 맞췄어요 / 방금 것을 되돌렸어요 / 버린 만큼 뺐어요 / 보관 위치를 옮겼어요 / 나눠 담았어요 / 개봉으로 표시했어요). 수량 줄 ‘계란 8개 → 4개’ + 추정/명시값 칩 항상. 개봉·이동은 ‘수량 변화 없음’. 칩: 입고·사용·보정·취소·폐기·이동·소분·개봉
· 마이페이지: 기본 인분 [−] 2인분 [+](1~8), 호출어는 화살표 없음
이 폴더의 구성과 다시 만들기
screens/     화면 HTML(*.dc.html)과 런타임 support.js(React 포함, 외부 CDN 없이 동작)
assets/      글꼴(Pretendard·배민 주아체, OFL 라이선스 동봉)과 간편 로그인 로고
png/         화면별 2배율 PNG
today-meal-mockup.html  Figma 같은 단일 뷰어(확정안 83화면, 글꼴 포함, 이 파일만 보내도 열림)
figma/       Figma 가져오기용 정적 보드 6장(스크립트·애니메이션 없음, 행마다 한 장)
animated/    움직이는 보드 6장(애니메이션 그대로, 서버 없이 더블클릭으로 열림)
manifest.json  보드 제목·묶음·크기·원본/내보낸 파일 sha256

  node mockup/tools/render_png.js           PNG 다시 찍기 (Playwright 필요)
  node mockup/tools/figma_pack.js           figma/ 보드 다시 만들기 (Playwright 필요)
  node mockup/tools/figma_pack.js --animated   animated/ 보드 다시 만들기
