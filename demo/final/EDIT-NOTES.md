# 시연 영상 편집 기록

원본 `long/`·`edit/` 는 읽기만 했다. 다시 만들 때는 `.venv/bin/python render.py all`.

저장소에는 확정본 세 편(`today-meal-90s-v3.mp4`·`today-meal-full-v3.mp4`·`voiceover/today-meal-90s-v4-ai-voice-leda.mp4`)과
스크립트만 둔다. 촬영 원본 `long/`·챕터 편집본 `edit/` 은 로컬 전용이고, `work/`·이전 판·후보본·whisper 모델은
제출 후 정리했다(2026-10-01). 아래 기록의 해당 경로는 당시 기준이다.

| 파일 | 길이 | 형식 |
|---|---|---|
| `today-meal-full.mp4` | 6분 6초 | 1920×1080 · 30fps · H.264 · AAC 48kHz |
| `today-meal-90s.mp4` | 88초 | 같음 |

화면은 왼쪽 폰 화면, 오른쪽 챕터 제목과 기능 자막이다. 소리는 목소리와 앱 음성을 섞은 기본 트랙이다.

## 확인한 것

- 받아쓰기(whisper)로 발화와 앱 응답을 시각별로 뽑아 편집했다. 모든 호출이 "헤이 키친 → 띠딩 → 명령 → 확인 → 결과" 순서로 온전하다.
- 자른 지점이 말소리·앱 응답 안에 들어가지 않는지 자동 검사했다. 두 영상 모두 0건.
- 각 구간은 같은 원본에서 영상과 소리를 함께 잘라 싱크가 유지된다.
- 앱 응답 이중 녹음은 녹음 단계에서 줄였다(앱 소리가 날 때 마이크를 낮춤). 소리는 직접 들어서 확인해 주세요.

## 촬영 결과를 따른 자막

- 05 인분 변경은 실제로 **2인분 → 3인분(삼겹살 200g → 300g)** 이었다. 4인분으로 적지 않았다.
- 05 조리 중 음성 명령 "다음", "타이머 3분", "다시 읽어 줘"는 촬영에서 동작해 자막으로 넣었다.
- 07 기한 알림은 화면에 표시 변화가 보이지 않아 "기한 알림 설정"만 적었다.
- 06 영상 레시피는 완료해도 재고를 빼지 않는다고 적었다. 분석 결과가 바로 나와 "새로 분석"이라고 적지 않았다.
- 정정("두 개가 아니라 세 개")·취소는 촬영하지 않아 넣지 않았다.

## 편집 결정

- **계정:** 01은 로그인이 아니라 회원가입으로 들어간다. 입력 과정은 키 터치로 비밀번호가 보여 빼고, 가입 버튼 장면은 이메일·비밀번호 칸을 흐리게 가렸다.
- **유튜브:** 06의 유튜브 앱 화면은 다른 영상 소리가 나와 소리를 껐다.
- **재고 일관성:** 05 끝의 냉장고 화면은 계란이 10개로 찍혀(04 결과는 4개) 넣지 않았다. 차감 결과 화면(삼겹살 300g→100g, 두부 2모→1모)에서 끝낸다.
- **반복 압축:** 02는 첫 등록만 끊지 않고, 나머지 세 번은 말·결과·홈 이동만 남겼다("확인 대기 일부 생략").
- **90초 순서:** 기한별 슬라이드(재료 4가지)를 등록보다 먼저 두면, 로그인 직후 빈 냉장고 → 슬라이드(4가지) → 빈 냉장고에서 등록으로 순서가 모순된다. 그래서 **등록(7~27초) → 슬라이드(27~35초)** 로 두 구간만 바꿨다. 나머지 구간 길이는 요청대로다.

## 90초 구성

| 시간 | 장면 | 원본 |
|---|---|---|
| 0~7 | 스플래시 → 로그인 화면 → 가입(가림) → 권한 → 홈 | 01 |
| 7~27 | 음성 등록: 계란 열 개, 유통기한 10월 4일 | 02 |
| 27~35 | 홈 기한별 슬라이드(재료 4가지 등록 후) | 03 |
| 35~43 | "두 개 썼어" → 8개, "네 개 남았어" → 4개 | 04 |
| 43~66 | 삼겹살로 뭐 해먹을까 → 추천 → 2→3인분 | 05 |
| 66~78 | 조리 안내 · "타이머 3분" → 완료 차감 | 05 |
| 78~85 | 유튜브 링크 → 재료·단계 정리 | 06 |
| 85~88 | 홈과 마무리 | 08 |

## 전체 시연본 구성

인트로 카드 → 01 시작(18초) → 02 등록(77초) → 03 기한별 확인(29초) → 04 사용·잔량 보정(41초)
→ 05 추천·조리(96초) → 06 영상 레시피(45초) → 07 설정(25초) → 08 복구와 마무리(27초) → 엔딩 카드.

## 영상에 남아 있는 것

- 04 기록 화면에 영어 "undo" 말풍선(촬영 전 되돌리기 흔적)이 보인다.
- 05 메뉴 상세의 재료가 모두 "있어요"로 보인다(촬영 뒤 서버에서 고침).

## v2 (검수 반영)

v1(`today-meal-full.mp4`, `today-meal-90s.mp4`)은 그대로 두고 `-v2` 파일을 새로 만들었다.

1. **인분 연결:** 원본은 34.9초 3인분(300g) → 35.1초 2인분(200g)으로 되돌린 뒤 35.6초부터 조리 화면으로 넘어간다.
   되돌린 2인분 화면(35.45초)을 1.2초 멈춰 보이고 "확인 후 2인분으로 조리"를 적었다. 완료 차감 자막에 "(2인분)"을 붙였다.
2. **생략 표시(90초):** 시작 구간 "2026.10.01 촬영", 사용·추천·유튜브 구간 "대기 구간 단축", 조리 구간 "조리 단계 일부 생략".
   전체본 인트로 카드에도 촬영일을 적었다.
3. **음성 컷 재검토:** 50ms 창 RMS로 경계를 다시 쟀다(사람이 들은 확인 아님).
   - 04 "계란 두 개 썼어": 5.20~6.25초. 컷 4.8초 → 문장 앞 0.4초 여유, 잘림 없음.
   - 04 "계란 4개 반영했어요": 29.70~31.35초. 컷 29.5 → 29.0초로 여유를 늘림.
   - 05 "3분 타이머를 시작할게요": 54.45~56.25초 뒤 무음. 컷 56.6 → 56.9초로 늘림. 받아쓰기의 58.04초는 추정 오차.
   - 전 구간 경계 ±0.15초 안에 -40dB 넘는 소리가 없는지 검사해 3곳(05 1.8·35.95·51.4초)을 무음 쪽으로 옮겼다. 재검사 0건.

## v3 (90초 · 배경음악)

`today-meal-90s-v3.mp4` = v2.1 화면 + 배경음악. 비교용 무음악판은 `today-meal-90s-v2.mp4`·`v2.1.mp4`.

- 곡: Somewhere Sunny — Kevin MacLeod (incompetech.com), CC BY 4.0. 출처·라이선스는 `music/LICENSE.md`, 마지막 화면에 표기.
- 말·호출음·앱 음성 구간은 0.25초 앞서 0.35초에 걸쳐 13dB 낮춘다. 2초 안쪽 간격은 이어 붙여 출렁이지 않게 했고,
  첫 등록(헤이 키친 → 띠딩 → 명령 → 결과)은 통째로 낮춘다. 효과음은 넣지 않았다.
- 시작 1.5초 페이드인, 마지막 장면 +2dB 뒤 2.5초 페이드아웃. 곡이 59.5초라 45초에서 처음부터 다시 잇고(2.5초 교차),
  이음매는 음악이 낮아진 구간(42.5~45초)에 둔다.
- 측정(재조정 후): 말 구간에서 말이 음악보다 10.8~ dB 크다(중앙 15.9). 말 없는 구간 음악 약 -24.6dB RMS(말소리 약 -23dB).
  true peak -1.0dBFS, 클리핑 0. 통합 -21.0 LUFS.
- 처음 만든 판(음악 -33dB)은 노트북 스피커에서 거의 들리지 않아 `work/today-meal-90s-v3-quiet.mp4` 로 옮기고 8dB 키웠다.
- 귀로 들은 확인은 아니다. 음악 크기 취향은 `mix_bgm.py`의 `BED_LUFS`·`DUCK_DB` 로 조절한다.

## v4 (90초 · 사용자 음성 AI 후시 녹음, 2026-10-01)

`voiceover/today-meal-90s-v4-ai-voice-leda.mp4` — v3 그림 + 오른쪽 위 "사용자 음성 · AI 후시 녹음" 표시.
v3·전체본·원본은 그대로 두었다. 다시 만들 때는 `GEMINI_API_KEY=... .venv/bin/python voiceover.py short B`.

- 목소리: Gemini TTS(gemini-3.8-flash-tts) Leda. 후보 비교본은 `voiceover/candidates/`.
- 앱 응답·띠딩은 원본 녹화의 폰 재생음 트랙 원음. 헤드셋 마이크 트랙만 뺐다.
- 발화 7개(헤이 키친·계란 열 개·유통기한, 두 개 썼어, 네 개 남았어, 삼겹살로 뭐 해 먹을까, 타이머 3분)를
  원래 구절 자리에 놓았다. 구절 끝을 원래와 맞춰 화면 받아쓰기가 말보다 먼저 뜨지 않는다(속도 ×0.92~1.10).
  구절별 시각은 `voiceover/README.md`.
- TTS 출력 끝 약 120ms 에 붙어 나오는 잡음("지직")은 잘라낸다. 결과 대사 트랙에서 잡음 틀 0.
- 배경음악: 같은 곡·설정, 줄이는 구간만 새 대사 트랙 기준으로 다시 계산. 말이 음악보다 최소 16.6dB 크다.
- 측정: 통합 -20.9 LUFS, true peak -3.8 dBFS. 소리·화면 차이 -12ms(1틀 안).

### v3 에서 발견한 싱크 문제

- v3(배경음악판·무음악판)은 소리가 화면보다 앞섰다. 계란 등록 띠딩 0.8초 → 타이머 응답 0.43초.
  구간 파일을 `concat -c copy` 로 이을 때 생긴 것으로 보인다. v4 는 대사 트랙을 구간 영상 길이에 맞춰 한 번에 만들어 없앴다.
- 같은 방식으로 이은 전체 시연본(`today-meal-full-v3.mp4`)은 확인·수정하지 않는다(2026-10-01 결정).
